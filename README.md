# Huntly Street Flat

A no-build, static GitHub Pages site for showcasing the Huntly Street flat. The page is organised around a floorplan-led overview, concise room notes, photo placeholders, and a viewing call-to-action.

## Publish with GitHub Pages

You do not need to run the site locally or install any dependencies.

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the current branch and choose the repository root (`/`) as the source.
5. Save the settings and wait for GitHub Pages to publish the site.

## Edit the content

- `index.html` contains the page copy, room notes, floorplan labels, captions, and viewing email.
- `styles.css` contains all layout and visual styling.

## Add real photos later

Create an `assets/` folder, place your final photos there, and replace the placeholder blocks in `index.html` with image tags, for example:

```html
<img src="assets/living-room.jpg" alt="Living room with sofa and window" />
```
