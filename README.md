# Huntly Street Flat

A static GitHub Pages site for showcasing a flat with room highlights, floorplan overview, photo placeholders, location notes, and viewing contact details.

## Publish with GitHub Pages

No local build step is required.

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the current branch and the repository root (`/`) as the source.
5. Save the settings and wait for GitHub Pages to publish the site.

## Customise the site

Edit these files directly:

- `index.html` — page content, room descriptions, viewing email, and section order.
- `styles.css` — colours, spacing, floorplan styling, and responsive layout.
- `script.js` — small progressive enhancements.

Replace the placeholder photo cards and stylised floorplan with final images when they are ready.
